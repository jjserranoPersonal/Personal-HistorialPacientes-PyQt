# Glosario

## Términos Médicos

- **HEA (Historia Enfermedad Actual)**: Descripción del problema de salud actual del paciente
- **APP (Antecedentes Personales Patológicos)**: Historia de enfermedades previas del paciente
- **APF (Antecedentes Personales Fisiológicos)**: Información sobre desarrollo físico y fisiológico del paciente
- **Impresión Diagnóstica**: Conclusión médica sobre el estado del paciente
- **Conducta a Seguir**: Plan de tratamiento o acciones médicas recomendadas
- **Motivo de Consulta**: Razón por la cual el paciente busca atención médica
- **Signos Vitales**: Temperatura, tensión arterial, frecuencia cardíaca, respiratoria, oxigenación

## Términos Técnicos

- **PyQt5**: Framework para desarrollo de interfaces gráficas en Python
- **SQLite**: Base de datos embebida ligera
- **MySQL**: Sistema de gestión de base de datos relacional
- **ReportLab**: Librería para generación de PDFs
- **CRUD**: Create, Read, Update, Delete - operaciones básicas de datos
- **ORM**: Object-Relational Mapping - mapeo objeto-relacional
- **UI**: User Interface - interfaz de usuario
- **GUI**: Graphical User Interface - interfaz gráfica de usuario
- **API**: Application Programming Interface - interfaz de programación de aplicaciones
- **SQL Injection**: Ataque de inyección de código SQL
- **RBAC**: Role-Based Access Control - control de acceso basado en roles

## Acrónimos

- **DB**: Database - base de datos
- **ID**: Identification - identificación
- **PDF**: Portable Document Format - formato de documento portable
- **JSON**: JavaScript Object Notation - notación de objetos JavaScript

# Capturas de Pantalla

Debido a limitaciones técnicas, no se incluyen capturas de pantalla reales de la aplicación.

Para visualizar las interfaces:

1. Ejecutar la aplicación: `python MainWindow_Login.py`
2. La aplicación tiene las siguientes pantallas principales:
   - Pantalla de Login: Formulario de usuario y password
   - Pantalla Principal: Tabs para Pacientes, Eventos, Historial, Soportes, Listado

Descripciones detalladas en PANTALLAS.md
